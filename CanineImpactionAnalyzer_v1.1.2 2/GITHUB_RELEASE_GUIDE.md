# GitHub Release Guide

1. Create a GitHub account if you do not already have one.
2. Create a new repository named:
   `Canine-Impaction-Analyzer`
3. Upload the source files from this package.
4. Add README.md, RELEASE_NOTES.md, and COPYRIGHT.txt.
5. Create a GitHub Release named:
   `Canine Impaction Analyzer v1.0.0`
6. Attach only your clean release packages:
   - macOS application ZIP/DMG
   - Windows installer/ZIP
7. Paste the SHA-256 checksums into the release description.
8. State clearly that the software is for research use and is not yet
   clinically validated.

For best user trust, publish only digitally signed builds.
